Descripción general

Soy desarrollador de software y cofundador de KOVELT, un estudio que crea herramientas digitales a medida para negocios: sitios web, aplicaciones, sistemas de gestión e integraciones.

Por mi cuenta desarrollo A la par, una app de finanzas compartidas. También armo proyectos de electrónica con Arduino y ESP32, como un asistente de voz.

  • Aplicaciones web con Next.js, TypeScript y Supabase
  • Sitios para negocios reales, desde el diseño hasta la publicación
  • Prototipos de hardware con Arduino y ESP32
  • Trabajo en equipo con Git y GitHub
  • En estudio: arquitectura de software y sistemas embebidos
